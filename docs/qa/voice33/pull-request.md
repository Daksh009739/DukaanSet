VoiceOS previously opened in a manual mode and stopped after duplicate-customer questions. It now opens into the default hands-free greeting → listening → final utterance → spoken response → listening cycle, with a latched Pause/Resume control and immediate audio cleanup on close or scope changes.

When Rahul already exists, an explicit separate-customer answer prepares a distinct editable Rahul draft. Spoken confirmation saves the exact reviewed snapshot once, preserves the original customer and rejects a conflicting phone. Success waits for authenticated readback. Uncertain customer, sale, payment, expense, catalogue and stock requests check the committed receipt before retrying; a failed status check cannot fall through into a write.

The assistant uses a compact deep-teal/mint conversation layout with a persistent composer and confirmation, automatic language precedence and genuine persisted voice selection. The approved dashboard/sidebar/header composition remains intact. This cumulative branch also contains the previously reviewed premium business workspaces, dashboard card colours and application header controls.

Validation: 323 unit/backend tests and 53 browser regression scenarios pass, along with lint, type checking, locale parity and the isolated production build. The compiled review passes 30 multilingual layouts and 18 accessibility scans. The new VoiceOS suite checks the hands-free duplicate conversation with zero manual microphone clicks, actual test-database writes, readback timing, lost-acknowledgement recovery and 12 multilingual layouts.
